1. 何をするサービスか

OWL JS Studio は、ブラウザ上で JavaScript の設定を書き換え、自分の3択クイズを作る学習特典です。学習者は GitHub Pages の学習画面だけを使います。完成したクイズは、登録メールへ HTML ファイルとして届きます。

学習画面（学習者に案内する URL）：

https://owltecrecruiter.github.io/owl-js-studio/

特典コードの発行画面は学習画面とは別です。発行画面の URL と管理者パスワードは社内だけで共有し、学習者や公開資料には載せないでください。

2. 当日の役割

役割使う画面やること
面接官・講師 特典コード発行画面 応募者氏名とメールを登録し、8文字の特典コードを渡す
学習者・応募者 OWL JS Studio 最初に特典コードを入力して学習を開始し、STEP 1〜5 を進めたあと CLEAR から作品を受け取る
運営（技術） メール・Drive・発行記録 届かない場合の確認、再送、コード失効の判断

3. 特典コードの発行

  1. 社内の発行画面を開き、管理者パスワードで操作します。
  2. 応募者氏名とメールアドレスを入力します。完成クイズはこのメールへ届きます。
  3. 「発行コードを生成する」を押します。
  4. 表示された 半角英数字8文字 のコードをコピーするか、「特典カードを印刷」して手渡します。
  5. 学習者には「ハイフンは不要」「有効期限は発行から1か月」「作品の受け取りは1回だけ」と伝えます。
発行したコードの平文は、画面を閉じると再表示できません。印刷またはコピーをその場で済ませてください。有効期限は発行から1か月です。作品を受け取ったコードは再利用できません。学習開始だけでは消費しません。

学習者に伝えること

  • 学習 URL を開く
  • 最初の画面で特典コードを入力し、「学習をはじめる」を押す
  • STEP 1 から順に進める。最初からプレビューで遊ばなくてよい
  • 完成したら STEP 5 の横の CLEAR を押す
  • CLEAR ではコードの再入力は不要。認証済みのまま作品を受け取る
  • 登録メールの添付 HTML が完成作品

4. 学習者への案内

学習画面の左がガイド、中央がコード、右がプレビューです。プレビューは「作成中のクイズを試す画面」であり、学習の開始ボタンではありません。

画面の言葉意味
実行いまのコードをプレビューに反映する。STEP 2 以降で必要
ふりがなコードの意味を読むための表示。編集するときは OFF
CLEAR全 STEP 達成後に点灯。完成作品の受け取りへ進む
リセットコードを初期状態に戻す。学習途中では使わない

5. STEP 1〜5 の見守り方

STEP学習者がやることクリアの目安
1 プログラムを読む ふりがなを ON にする 実行は不要
2 タイトルを変える gameTitle の文字を変えて実行 タイトル画面の見出しが変わる
3 色を変える 背景色または文字色を変えて実行 画面の色が変わる
4 自分のクイズを作ろう 3問の問題文と、各問の選択肢3つ（合計12箇所）を変えて実行 問題文だけ変えてもクリアにならない
5 正解を設定しよう 3問のうち好きな1問の正解番号を変え、実行し、プレビューで新しい正解を選ぶ 「正解！」が出ればクリア。3問全部を変える必要はない

全 STEP を達成すると CLEAR が点灯します。そのあとはタイトルや問題を直しても、学習完了状態は残ります。ただし次の点だけ守ってもらいます。

  • 発行する前に、直したコードで「実行」を成功させる
  • 赤いエラーが出ているときは、直してから CLEAR を使う

6. 完成クイズの受け取り

  1. 学習者が CLEAR を開き、「発行を申請する」を押す。特典コードの再入力は不要です。
  2. 成功すると「発行申請が完了しました」と出る。
  3. 登録メールに件名 【OWL JS Studio】完成したクイズをお届けします が届く。
  4. 添付は作品タイトルの HTML（例：完成クイズ.html）。ダブルクリックでブラウザから遊べる。

運営側の Drive には 応募者氏名_作品タイトル.html として保存されます。メール添付名には氏名を付けません。

特典コードは作品の受け取りに1回だけ使えます。学習開始だけでは消費しません。入力を間違えて上限に達した場合は、時間をおくか、運営が別コードを発行します。受け取り済みのコードでは学習も発行もできません。

7. よくある質問

CLEAR が点灯しない

STEP 1〜5 がすべて終わっているか確認します。STEP 4 は問題文3つと選択肢9つの変更、STEP 5 は好きな1問の正解番号変更・実行・「正解！」確認が必要です。

CLEAR は点灯するが発行画面に進めない

コードにエラーがあるか、最後に直した内容を「実行」していないことが多いです。エラーを消し、実行してから CLEAR を押します。

特典コードが通らない

半角英数字8文字か、別の人のコードか、作品の受け取り済みか、発行から1か月を過ぎていないかを確認します。ハイフンは不要です。

メールが届かない

迷惑メール、添付 HTML のブロック、メールアドレスの打ち間違いを確認します。Drive にファイルがあれば、運営から再送できます。コードは使用済みのままなので、成功した発行をもう一度同じコードでやり直すことはできません。

4問目を足したい・選択肢を4つにしたい

できません。仕様で3問・各3択に固定しています。

8. やってはいけないこと

  • 特典コード発行画面の URL や管理者パスワードを学習者・SNS・GitHub Pages に載せない
  • 他人の特典コードを使わせない。1人1コード
  • 初期コードのまま発行させない。必ず STEP を完了してから CLEAR へ
  • 完成 HTML を無断で公開共有しない。本人の作品として扱う

技術的な構成・デプロイ・テストは 技術マニュアル を参照してください。
