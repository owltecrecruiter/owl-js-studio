GASブリッジ接続テスト v0.7

GitHub Pages から GAS HTML Service への postMessage 接続だけを確認します。 発行コード、メールアドレス、クイズデータ、作品データは送信しません。

GAS側は更新済みの gas/IssuanceBackend.js を貼り付けて再デプロイした Web App を使ってください。 推奨構成は learner-only ブリッジを Who has access: Anyone で公開し、 LEARNER_PAGE_ORIGIN をこのページのオリジンと完全一致させる構成です。 Only myself の Web App は GitHub Pages 埋め込み learner フローには使わないでください。

  1. GAS Web App の URL を下の欄に貼り付けます。
  2. 「接続テストを開始」を押すと iframe を読み込みます。
  3. iframe URL の query と hash の両方に一回限りの bridgeSession を付け、GAS からの ready を待ちます。
  4. ready の origin と bridgeSession を検証し、実際に応答した frame にだけ安全な ping を送ります。
通常は空欄のままで構いません。空欄でも https://*.script.googleusercontent.com および実際の HTML Service ホスト（https://*-script.googleusercontent.com）からの ready を許可し、session 一致後はその正確な origin だけを ping の targetOrigin に使います。明示指定する場合は観測した exact origin を入れてください。
